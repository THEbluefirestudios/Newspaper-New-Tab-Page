# Newspaper New Tab

a simple new tab page that looks like an old vintage newspaper.

has:
- dynamic date at the top
- search bar (searches google on enter)
- quick links
- vintage newspaper layout + fonts

just open [this link](https://pahal-desai.github.io/Newspaper-New-Tab-Page/) in your browser or set it as your browser's new tab page.

## what i learnt??
i learnt some really cool tricks of using css flexbox and grid to create a newspaper layout.
i also learnt how to use pseudo-elements and pseudo-classes to create a more vintage look.
